# Contributing to QuickShare-QR 🤝

Thank you for contributing to **QuickShare-QR**!

---

## 🛠️ Local Setup

1. **Clone:**
   ```bash
   git clone https://github.com/mahdyarmonfared/quickshare-qr.git
   cd quickshare-qr
   ```

2. **Install:**
   ```bash
   npm install
   ```

3. **Test:**
   ```bash
   npm test
   ```

---

## 🚀 Submitting Changes

1. Create a feature branch (`git checkout -b feat/my-improvement`).
2. Run `npm test` to verify zero regression.
3. Open a Pull Request to `main`.

Happy sharing! ⚡
